Before you start

Torque values and specs shown here are reference information only, compiled from a mix of official service literature, community/tuner sources, and — where marked — self-reported by other users and not independently verified. Each entry is labeled with its source tier.

Always verify safety-critical specs — wheels, suspension, brakes, steering — against OEM documentation before doing any work. This app is not affiliated with, endorsed by, or sponsored by any vehicle manufacturer.

This is a private beta test build — for the invited tester's own evaluation use only, not for redistribution to anyone else. Basic usage (pages visited, app version) is logged so the developer can see it's being used; no location or other personal data is collected.

Use of this app and its data is at your own risk.
