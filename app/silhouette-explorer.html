Before you start

Torque values and specs shown here are reference information only — official, community/tuner, and self-reported sources are each labeled. Not a substitute for your vehicle's official service manual.

Always verify safety-critical specs — wheels, suspension, brakes, steering — against OEM documentation before doing any work. This app is not affiliated with, endorsed by, or sponsored by any vehicle manufacturer.

This is a private beta test build — for the invited tester's own evaluation use only, not for redistribution. Basic usage is logged so the developer can see it's being used; no location or other personal data is collected.
